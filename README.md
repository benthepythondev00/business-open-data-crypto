# Business Data: Open Data, Crypto & Startups for Gemini CLI

Government open-data search, Binance and Bitstamp tickers, Crypto Fear & Greed, Bitcoin stats, Bank of Canada FX and new startups.

This extension connects Gemini CLI to the hosted MCP server [Business Data: Open Data, Crypto & Startups](https://mcpize.com/mcp/business-open-data-crypto). It reads public pages only and needs no login or cookies for the source itself.

## Install

```
gemini extensions install https://github.com/benthepythondev00/business-open-data-crypto
```

Gemini CLI asks for your MCPize API key once and keeps it in the system keychain.

## Get a key

1. Open https://mcpize.com/mcp/business-open-data-crypto and subscribe. The Free plan needs no card.
2. Copy the API key shown on the server page.
