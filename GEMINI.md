# Business Data: Open Data, Crypto & Startups

Government open-data search, Binance and Bitstamp tickers, Crypto Fear & Greed, Bitcoin stats, Bank of Canada FX and new startups.

Use the tools of the `Business Data: Open Data, Crypto & Startups` MCP server when the user asks for this data. Ask for a small `limit` first and widen it only when asked. If a call answers 401, the MCPize API key is missing or expired: tell the user to run `gemini extensions config` for this extension.
